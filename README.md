# XPCS Analysis Workflow at CHX

## Overview

This repository contains Jupyter notebooks for analyzing X-ray Photon Correlation Spectroscopy (XPCS) measurements performed at the Coherent Hard X-ray (CHX) beamline at the National Synchrotron Light Source II (NSLS-II), Brookhaven National Laboratory.

The repository includes temperature-specific XPCS analysis notebooks covering measurements from **170 K to 220 K**, along with a notebook for retrieving archived process-variable (PV) data for temperature-stability analysis.

The notebooks provide a starting point for processing and analyzing experimental XPCS datasets. Please refer to the individual notebooks for the specific analysis procedures, parameters, and outputs implemented for each dataset.

## Analysis Workflow

The notebooks are organized by measurement temperature and dataset. The general workflow for using this repository is:

1. **Select the dataset:** Open the notebook corresponding to the temperature and dataset you want to analyze.
2. **Check the configuration:** Review the notebook's input paths, experimental parameters, regions of interest (ROIs), and other configuration settings.
3. **Verify data access:** Ensure that the experimental data and any required beamline-specific scripts or packages are accessible.
4. **Run the analysis:** Execute the notebook cells in sequence, following the procedures implemented in that notebook.
5. **Review the results:** Examine the intermediate outputs, plots, and fitted parameters generated by the analysis.
6. **Check reproducibility:** Record the notebook version, input dataset, and analysis settings used to produce the results.

The exact processing steps and analysis methods may differ between notebooks. Consult the relevant notebook for implementation details.

## Requirements

To work with these notebooks, you will need:

* Python
* Jupyter Notebook or JupyterLab
* The Python packages imported by the individual notebooks
* Access to the experimental datasets used in the analysis
* Access to any external beamline-specific scripts, libraries, or utilities referenced by the notebooks

The complete list of dependencies should be determined from the import statements and setup cells in each notebook. Experimental data and external dependencies may not be included in this repository.

## Getting Started

1. Clone or download this repository from GitHub.
2. Set up a Python environment with Jupyter Notebook or JupyterLab.
3. Install the required Python packages and configure access to the relevant experimental data.
4. Open the notebook corresponding to your dataset.
5. Review the notebook and update local file paths or configuration settings as necessary.
6. Execute the cells in order and inspect the resulting outputs.

Before running a notebook, verify that its configuration matches your dataset and computing environment.

## Reproducibility and Data Management

For reliable and reproducible analysis:

* Keep a record of the input dataset and notebook version used.
* Document changes to file paths, experimental parameters, and analysis settings.
* Preserve the original experimental data.
* Keep analysis outputs organized and distinguish them from input data.
* Compare similarly named notebooks before assuming they implement identical procedures.
* Follow the applicable facility requirements for experimental-data access, storage, and sharing.
